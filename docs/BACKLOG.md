# Backlog (pattern)

Park decisions and handoffs **in this repo**, not in a task app, unless the operator asks.

This committed file is the **shape** only:

- A parked row needs a re-open trigger.
- Agents remind from the live list after extract work — they do not invent a second reminder channel.
- When a row becomes active, mark it promoted with the date.

**Live rows for this machine** live in `BACKLOG.local.md` (gitignored) if that file exists. Cloud clones will not see it. Do not put Saved-library URLs, inbox IDs, or personal names in *this* file.
